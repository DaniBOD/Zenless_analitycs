## 0. TL;DR

Después de cerrar la detección S18 + parseo OCR (commit `7267f40`), el `.exe` capturaba stats pero con tres problemas observados en QA real:

1. **Captura no-determinista frame-a-frame** — Tesseract devolvía PV en una F8 y `None` en la siguiente sobre el mismo PJ inmóvil.
2. **F8 no disparaba con ZZZ enfocado** — `pynput.keyboard.Listener` no recibe eventos cuando el juego en pantalla completa tiene foco.
3. **Sin feedback sobre completitud** — el log mostraba sólo los stats que sí captó, sin indicar qué faltaba ni si era una extracción exitosa o parcial.

Esta sesión cierra las tres con: `AgentStatsAggregator` (madura stats entre F8s), Win32 `RegisterHotKey` (F8 global a nivel OS), y log rol-aware `[completo]`/`[parcial]` (Disruptivos requieren `fuerza_bruta`, el resto `tasa_perforacion`).

Tests: **+9 nuevos en `test_agent_stats_aggregator.py` (todos verdes)** sobre el aggregator. Suite completa estable.

## 2. Cambios implementados

### 2.1 `AgentStatsAggregator` — madurez entre capturas

**Archivo:** [`app/core/parser_agent_stats.py`](app/core/parser_agent_stats.py)

Nueva clase que mantiene "el mejor estado conocido" del agente actual y mergea cada nueva captura field-by-field, preservando valores previos cuando el nuevo es `None`.

```python
class AgentStatsAggregator:
    def __init__(self) -> None:
        self._best: AgentStatsParsed | None = None

    @property
    def has_any(self) -> bool: ...

    @property
    def current_agent(self) -> str | None: ...

    def reset(self) -> None: ...

    def merge(self, new: AgentStatsParsed) -> AgentStatsParsed:
        """Mergea `new` sobre el mejor conocido. Reset auto si cambia el agente."""
        # 1. Detectar cambio de agente → reset
        if (self._best is not None
                and self._best.agente_nombre
                and new.agente_nombre
                and self._best.agente_nombre != new.agente_nombre):
            self.reset()

        # 2. Primer merge: clonar
        if self._best is None:
            self._best = replace(new)
            return self._best

        # 3. Merge field-by-field: gana el no-None más reciente
        for k in _AGGREGATABLE_FIELDS:
            new_val = getattr(new, k)
            if new_val is not None:
                setattr(self._best, k, new_val)
        return self._best
```

**Comportamiento clave:**

| Captura | PV | ATK | DEF | CR | Estado del aggregator |
|---------|-----|-----|-----|-----|----------------------|
| #1 (Nangong) | 10797 | 2531 | — | — | PV=10797, ATK=2531 |
| #2 (Nangong) | — | 2531 | 925 | — | PV=10797, ATK=2531, DEF=925 |
| #3 (Nangong) | — | — | — | 19.4% | PV=10797, ATK=2531, DEF=925, CR=19.4% |
| #4 (Yuzuha)  | 12000 | — | — | — | **reset** → PV=12000 (Nangong descartado) |

**Tests nuevos:** [`app/tests/unit/test_agent_stats_aggregator.py`](app/tests/unit/test_agent_stats_aggregator.py) — 9 tests, cubren:

- Primer merge clona input

### 2.2 Wiring del aggregator en `monitor._process_agent_stats`

**Archivo:** [`app/core/monitor.py`](app/core/monitor.py)

```python
self._stats_aggregator = AgentStatsAggregator()  # instance

def _process_agent_stats(self, frame, state):
    try:
        raw_stats = parse_agent_stats(frame, self._ocr)
        stats = self._stats_aggregator.merge(raw_stats)
        log.info("Stats agente (post-merge): Nv=%s PV=%s ATK=%s DEF=%s conf=%.2f", ...)
        if self._on_agent_stats:
            self._on_agent_stats(stats, state)
    except Exception as exc:
        ...
```

El aggregator es **instance-level** en `Monitor`, sobrevive entre F8s, y se resetea automáticamente al cambiar de agente (detectado por `agente_nombre` en el OCR).

### 2.3 F8 global vía Win32 `RegisterHotKey`

**Archivo:** [`app/core/hotkeys.py`](app/core/hotkeys.py)

Refactor del backend de hotkeys:

- **Backend primario:** Win32 `RegisterHotKey` via ctypes + `user32.dll` + message loop en thread daemon. Recibe la tecla a nivel OS, antes de que ZZZ la consuma.
- **Backend fallback:** `pynput.keyboard.Listener` (legacy, sólo cuando Win32 falla — útil en pruebas no-Windows).

```python
VK_F8 = 0x77
MOD_NOREPEAT = 0x4000

def _start_win32(callbacks):
    user32 = ctypes.windll.user32
    thread = threading.Thread(target=_message_loop, args=(callbacks,), daemon=True)
    thread.start()

def _message_loop(callbacks):
    for hotkey_id, vk in enumerate(callbacks):
        user32.RegisterHotKey(None, hotkey_id, MOD_NOREPEAT, vk)
    while True:
        msg = MSG()
        if user32.PeekMessageW(byref(msg), 0, 0, 0, PM_REMOVE):
            if msg.message == WM_HOTKEY:
                callbacks[msg.wParam]()
        time.sleep(0.01)
```

**Validado en juego:** F8 dispara correctamente con ZZZ en pantalla completa con foco.

### 2.4 `force_scan()` resetea dedup + buffer

**Archivo:** [`app/core/monitor.py`](app/core/monitor.py)

Cuando el usuario aprieta F8, queremos garantizar que la próxima captura no esté bloqueada por dedup ni filtrada por TemporalBuffer:

```python
def force_scan(self) -> None:
    self._reported_agent_stats_state_code = None
    self._processed_disc_state_code = None
    if self._buffer is not None:
        self._buffer.reset()
    if self._on_diagnostic:
        self._on_diagnostic("F8: scan manual forzado")
```

El log muestra explícitamente `[diag] F8: scan manual forzado` para que el usuario sepa que la pulsación fue recibida.

### 2.5 Auto-retry cuando stats no son útiles

**Archivo:** [`app/core/monitor.py`](app/core/monitor.py)

Si `parse_agent_stats` devuelve un resultado donde PV, ATK y DEF son todos `None`, no commiteamos el dedup ni dejamos el buffer en `last_emitted=S18`. Esto permite que el próximo frame intente de nuevo sin esperar transición de estado:

```python
def _stats_result_is_useful(stats: AgentStatsParsed) -> bool:
    return any(getattr(stats, k) is not None for k in ("pv", "ataque", "defensa"))

# En _maybe_process_agent_stats:
if not _stats_result_is_useful(merged_stats):
    self._buffer.reset()  # forzar re-detección S18 en próximo frame
    return  # NO commitear dedup
self._reported_agent_stats_state_code = state.code
```

### 2.6 Log rol-aware `[completo]` / `[parcial]`

**Archivo:** [`app/ui/controller.py`](app/ui/controller.py)

`_on_agent_stats_from_monitor` ahora emite **tres líneas** al LivePanel después de cada captura S18:

```
[reconocido] Nangong Yu — Ataque
[stats] Nv=60 PV=10797 ATK=2531 DEF=925 IMP=138 CR=19.4% CD=93.2% TA=173 MA=305 ER=1.2 TP=12%
[completo] extracción exitosa - 11/11 stats capturados
```

O bien:

```
[parcial] faltan 2/11: maestria_anomalia, recuperacion_energia - apretá F8 para reintentar (el aggregator va a completar)
```

Lógica rol-aware:

```python
rol_norm = (stats.rol or "").lower()
is_disruptivo = "disruptiv" in rol_norm
required_keys = [
    "nivel", "pv", "ataque", "defensa", "impacto",
    "prob_crit", "dano_crit", "tasa_anomalia",
    "maestria_anomalia", "recuperacion_energia",
]
required_keys.append("fuerza_bruta" if is_disruptivo else "tasa_perforacion")
missing = [k for k in required_keys if getattr(stats, k) is None]
```

Disruptivos (Yixuan, Vivian, etc.) requieren `fuerza_bruta` (su stat ofensivo principal). El resto de roles requieren `tasa_perforacion` (DPS Físico/Eléctrico/etc.). Esto evita falsos `[parcial]` para PJs donde un stat no aplica.

## 7. Lecciones aprendidas

- **OCR no-determinista exige aggregation, no perfección por frame.** Pretender que Tesseract devuelva los 11 stats en una sola captura es luchar contra la naturaleza de la herramienta. El aggregator + 3-5 F8s manuales es estructuralmente más barato que invertir en preprocessing perfecto.
- **`pynput` no sustituye a `RegisterHotKey` para juegos fullscreen.** Cualquier hotkey global pensado para usarse durante gameplay debe ir por Win32 directo.
- **Feedback explícito `[parcial]` con qué falta > silencio.** El usuario sabe qué stat re-disparar y por qué. Antes era ruido, ahora es señal accionable.
- **Rol-aware desde el modelo de dominio.** Disruptivos != DPS. Hardcodear `tasa_perforacion` como required hubiera dado `[parcial]` permanente para Yixuan. La regla `if "disruptiv" in rol` viene del schema (`agents.rol`), no de heurísticas.
